Use this tool to create and manage a structured task list for your current coding session. This helps track progress, organize complex tasks, and demonstrate thoroughness.

Use proactively for: multi-step tasks (3+ steps), non-trivial work, user-requested todo lists, after receiving new instructions, after completing tasks.

Task states: pending, in_progress (max one at a time), completed, cancelled.

When in doubt, use this tool. Keeping the todo list current helps the user see progress.
